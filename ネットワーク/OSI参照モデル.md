OSI参照モデルを**レイヤー1～7**で簡潔にまとめると、以下のようになります。

| レイヤー  | 名前         | 役割                   | 代表例                |
| ----- | ---------- | -------------------- | ------------------ |
| **7** | アプリケーション層  | アプリがネットワークを利用するための通信 | HTTP、DNS、SMTP      |
| **6** | プレゼンテーション層 | データの形式・暗号化・圧縮などを処理   | TLS、JPEG、UTF-8     |
| **5** | セッション層     | 通信の開始・維持・終了を管理       | セッション管理            |
| **4** | トランスポート層   | データを相手まで確実に届ける       | TCP、UDP            |
| **3** | ネットワーク層    | 宛先までの経路を決めて届ける       | IP、ルーター            |
| **2** | データリンク層    | 同じネットワーク内でデータを届ける    | Ethernet、Wi-Fi、MAC |
| **1** | 物理層        | 電気・光・電波などでデータを実際に伝送  | LANケーブル、光ファイバー、電波  |

### 覚え方

**7 → 1**の順に、

> **アプリ → データ形式 → 通信管理 → 届ける → 道を決める → 同じネットワーク → 電気・電波**

と考えると分かりやすいです。

ざっくり言えば、**上（7）ほど「人・アプリに近く」、下（1）ほど「機械・信号に近い」**です。
