# ルーティング・ネットワーク設計

## ルーティングプロトコル

ルーティングプロトコルは、ルーター間で経路情報を交換し、**宛先ネットワークへの経路を動的に決定するための仕組み**。

### スタティックルーティング

管理者が経路を手動で設定する方式。

* 構成が単純
* 経路を明示的に制御できる
* 大規模ネットワークでは管理負荷が高い
* 経路障害時に自動で別経路へ切り替えられない

### ダイナミックルーティング

ルーティングプロトコルを使用して、ルーター間で経路情報を自動的に交換する方式。

障害などによるネットワーク構成の変化に応じて、経路を再計算できる。

---

# OSPF

OSPF（Open Shortest Path First）は、**IGPとして使用されるリンクステート型の動的ルーティングプロトコル**。

同一組織内のネットワークで使用される。

## ネイバー

OSPFでは、隣接ルーターとネイバーを形成してルーティング情報を交換する。

ネイバーが正常に形成されないと、経路情報を正しく交換できない。

## リンクステートデータベース

LSDB（Link-State Database）は、ネットワークのリンク状態に関する情報を保持するデータベース。

各ルーターはLSDBをもとにネットワークのトポロジーを把握する。

## LSA

LSA（Link-State Advertisement）は、リンク状態などの情報を通知するために使用される。

LSAを交換することで、各ルーターのLSDBが構築される。

```text
LSA交換
   ↓
LSDB構築
   ↓
SPF計算
   ↓
ルーティングテーブル
```

## SPF

SPF（Shortest Path First）は、LSDBの情報をもとに最短経路を計算するアルゴリズム。

OSPFではダイクストラアルゴリズムを使用する。

## エリア

OSPFではネットワークをエリアに分割できる。

大規模ネットワークではエリアを利用して、LSDBの規模やルーティング情報の範囲を制御する。

---

# BGP

BGP（Border Gateway Protocol）は、**異なるAS（自律システム）間で経路情報を交換するためのルーティングプロトコル**。

インターネットなど、大規模なネットワーク間の経路交換に利用される。

OSPFなどのIGPとは異なり、BGPでは**ポリシーに基づいた経路制御**が重要になる。

```text
AS 100
   |
  BGP
   |
AS 200
```

---

# メトリック

メトリックは、複数の経路から最適な経路を選択するための評価値。

ルーティングプロトコルによってメトリックの定義は異なる。

基本的には、**メトリックが小さい経路を優先するプロトコルが多い**。

---

# アドミニストレーティブディスタンス

複数のルーティング情報源から同じ宛先への経路を学習した場合に、どの情報源を信頼するかを決めるための値。

**値が小さいほど優先度が高い**。

メトリックとは異なり、異なるルーティングプロトコル間の優先度を決めるために使用される。

---

# 経路広告

ルーターが自分の持つネットワークへの経路情報を他のルーターへ通知すること。

```text
Router A
   |
   | 経路広告
   ↓
Router B
```

Router Bは受け取った経路情報をもとにルーティングテーブルを構築する。

---

# コンバージェンス

ネットワークのトポロジーが変化した際に、ルーター間で経路情報が更新され、**新しい経路でネットワーク全体の状態が安定するまでの過程**。

障害発生時のコンバージェンスが速いほど、経路復旧までの時間を短縮できる。

---

# デフォルトルート

特定の宛先への経路がルーティングテーブルに存在しない場合に使用する経路。

```text
0.0.0.0/0
```

インターネット向け通信など、「その他すべての宛先」をまとめて扱う場合に利用される。

---

# 覚えておくポイント

* スタティックルーティングは管理者が経路を手動設定する
* ダイナミックルーティングはルーティングプロトコルによって経路を自動学習する
* OSPFはIGPのリンクステート型プロトコル
* OSPFはネイバーを形成して情報を交換する
* LSAを交換してLSDBを構築する
* LSDBをもとにSPFで最短経路を計算する
* OSPFではエリアによってネットワークを分割できる
* BGPはAS間の経路交換に使用される
* メトリックは経路の優劣を判断するための値
* アドミニストレーティブディスタンスは経路情報源の優先度を決める
* コンバージェンスはネットワーク変更後に経路情報が安定するまでの過程
* デフォルトルートは具体的な経路がない場合に使用する
