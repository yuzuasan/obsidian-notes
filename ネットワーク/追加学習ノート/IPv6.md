# IPv6

IPv6は、IPv4のアドレス枯渇などの問題に対応するために設計されたIPプロトコル。

IPv4と比べてアドレス空間が大幅に拡張されている。

---

# IPv6アドレス

IPv6アドレスは**128ビット**。

16ビットごとに区切り、16進数で表記する。

```text
2001:0db8:0000:0000:0000:0000:0000:0001
```

省略記法を使用すると、

```text
2001:db8::1
```

と表記できる。

## 省略ルール

### 先頭の0を省略

```text
0db8 → db8
0001 → 1
```

### 連続する0を`::`に省略

```text
2001:db8:0:0:0:0:0:1
↓
2001:db8::1
```

`::`は**1つのアドレスにつき1回だけ**使用できる。

---

# プレフィックス

IPv6では、ネットワーク部を**プレフィックス**で表す。

```text
2001:db8:1234:5678::1/64
```

`/64`の場合、先頭64ビットがネットワーク部。

```text
ネットワーク部        インターフェースID
<------ 64bit ------><------ 64bit ------>
2001:db8:1234:5678   ::1
```

一般的なIPv6ネットワークでは`/64`が多く使用される。

---

# IPv6アドレスの種類

## グローバルユニキャスト

インターネット上で使用できるIPv6アドレス。

```text
2000::/3
```

などが代表的な範囲。

IPv4のグローバルIPアドレスに相当する。

---

## リンクローカルアドレス

同一リンク内で通信するためのアドレス。

```text
fe80::/10
```

ルーターを越えて通信することはできない。

IPv6では、インターフェースにリンクローカルアドレスが自動的に設定されることがある。

---

## ループバックアドレス

自分自身を表すアドレス。

```text
::1
```

IPv4の`127.0.0.1`に相当する。

---

# SLAAC

SLAAC（Stateless Address Autoconfiguration）は、**ルーターから通知された情報を利用して、端末が自動的にIPv6アドレスを設定する仕組み**。

```text
端末
 ↓
ルーターからプレフィックス通知
 ↓
IPv6アドレスを自動生成
```

DHCPのようにサーバーから個別にアドレスを払い出す方式ではなく、端末自身がアドレスを構成できる。

---

# DHCPv6

DHCPv6は、IPv6ネットワークでDHCPを利用するための仕組み。

IPv4のDHCPと同様に、ネットワーク設定を自動的に提供できる。

SLAACとDHCPv6を組み合わせて利用することもある。

---

# NDP

NDP（Neighbor Discovery Protocol）は、**IPv6ネットワーク上で近隣ノードやルーターを発見するための仕組み**。

IPv4のARPが担っていた機能の一部を置き換える。

主にICMPv6を利用する。

主な機能：

* 近隣ノードのアドレス解決
* ルーターの発見
* プレフィックス情報の取得
* 重複アドレス検出

---

# ICMPv6

IPv6では、ICMPv6が重要な役割を持つ。

例えば、

* 疎通確認
* エラー通知
* NDP
* ルーター広告
* パケットサイズに関する通知

などに使用される。

IPv6では、ICMPv6を単純に遮断するとNDPなどが正常に動作しなくなるため、ファイアウォール設計では注意が必要。

---

# IPv4とIPv6の違い

| 項目       | IPv4      | IPv6           |
| -------- | --------- | -------------- |
| アドレス長    | 32ビット     | 128ビット         |
| 表記       | 10進数      | 16進数           |
| ARP      | 使用する      | 使用しない          |
| 近隣探索     | ARP       | NDP            |
| ブロードキャスト | あり        | なし             |
| 自動設定     | DHCPなど    | SLAAC / DHCPv6 |
| ループバック   | 127.0.0.1 | ::1            |

IPv6ではブロードキャストを使用せず、**マルチキャスト**などを利用する。

---

# IPv4枯渇

IPv4は32ビットのため、利用可能なアドレス数に限界がある。

```text
IPv4
32ビット
約43億アドレス
```

インターネットの普及によってIPv4アドレスが不足する問題が発生した。

IPv6では128ビットに拡張され、非常に大きなアドレス空間を確保している。

---

# デュアルスタック

デュアルスタックは、**IPv4とIPv6を同時に利用する方式**。

```text
          ┌─ IPv4 ─ Internet
Client ───┤
          └─ IPv6 ─ Internet
```

IPv4からIPv6へ一気に移行するのではなく、両方を並行して利用できる。

現在のIPv6移行では重要な方式。

---

# IPv6での通信イメージ

```text
端末
 ↓
IPv6アドレス設定
 ↓
NDPで近隣情報を取得
 ↓
デフォルトルーターを認識
 ↓
ルーティング
 ↓
IPv6ネットワーク
```

---

# 覚えておくポイント

* IPv6のアドレス長は128ビット
* IPv6アドレスは16進数で表記する
* `::`で連続する0を省略できる
* プレフィックスでネットワーク部を表す
* グローバルユニキャストはインターネット通信に使用する
* リンクローカルアドレスは`fe80::/10`
* ループバックアドレスは`::1`
* SLAACは端末がIPv6アドレスを自動構成する仕組み
* DHCPv6でもIPv6のネットワーク設定を提供できる
* NDPはIPv4のARPに相当する機能の一部を提供する
* NDPはICMPv6を利用する
* IPv6にはブロードキャストがない
* IPv4枯渇への対応としてIPv6が設計された
* デュアルスタックはIPv4とIPv6を並行して利用する方式
